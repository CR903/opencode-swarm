# 通用评审口径（_default）

> 就近祖先无 REVIEW.md 时的兜底口径：`resolveReviewDoc` 兜底链末端
> （就近祖先 → `_default.md` → null）。reviewer 只按本节判，不自由发挥。

## 算 bug（拦 approve，必须报 Important）

- 崩溃/异常退出：未捕获异常、空指针、越界、死循环/超时。
- 静默错：返回成功但数据错了（少写/多写/写错值，下游读到脏数据）。
- 越权写：写了不该写的路径（禁区文件、他人租户数据、漏 tenantId 读写）。
- 事务不完整：多步落盘缺回滚/缺幂等，中途失败留一半。

## 跳过（不报 finding）

- 纯注释/文档改动、格式化/重命名（行为零变）。
- 测试快照/固件更新（仅快照文件变化，无逻辑改动）。

## 举证格式

每条 finding 必须带：文件 + 行 + 复现命令（或实测输出）；`suggestion` 写最小修法。
